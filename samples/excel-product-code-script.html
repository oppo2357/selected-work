商品コード「007」と「7」、同じ棚に入れていい？

Excelで初めて商品リストを扱う方向けの縦型ショート台本。自主制作・50秒。商品と注文は架空です。

0–6秒

青いマグを頼んだのに、白い皿が来た。なぜ？

映像　青いマグと白い皿。注文票のコードはどちらも「7」。

6–15秒

マグはゼロゼロなな、皿はなな。エクセルが数値として読むと、同じ番号になります。

映像　元のCSVと注文票を横に並べる。「007」が「7」に変わった箇所に下線。

15–29秒

空のブックのデータタブから、元のシーエスブイを選んでインポート。プレビューが開いたら「データの変換」です。

映像　空のブックで［データ］→［テキスト/CSVから］。元ファイルを選んで［インポート］。プレビュー右下の［データの変換］を拡大。

29–43秒

商品コードの見出しの左、「いち、に、さん」を押して「テキスト」を選びます。確認が出たら「現在を置換」です。

映像　新しく開いた画面で、商品コード列の見出し左にある「123」を拡大。［テキスト］を選び、確認が出たら［現在を置換］。

43–50秒

ゼロが戻りました。左上の「閉じて読み込む」で完了です。

映像　2行の違いを2秒表示。左上の［閉じて読み込む］を押し、注文票と青いマグを映す。

Windows版Excelを想定。操作の出典は Microsoft サポート「先頭のゼロおよび大きい数値の保持」。
